The idea in 60 seconds

A recurrent model reads a sequence one token at a time and squeezes everything it has seen into a fixed-size hidden state. That is what makes it fast (constant memory per step, linear time overall), but it also means the state must decide what to keep. Classic state space models (SSMs) like S4 update the state with the same rule for every token: h ← Ā·h + B̄·x. The step size Δ that sets Ā = e−Δ (how much is forgotten) and B̄ = 1 − e−Δ (how much is written) is a fixed number, independent of what the token says.

That is a problem whenever only some tokens matter. With a small fixed Δ the state remembers a long way back, but every filler token leaks in and old colours never fully fade. With a large fixed Δ each token overwrites the state, so by the end it holds only the last filler. No single setting works, which is what the accuracy curve on the right shows.

Mamba's fix is to make Δ (and B and C) functions of the current token. Here Δt = softplus(w·xt + b): for a filler token Δ is near zero, so the state is left untouched and the token is effectively skipped; for a colour token Δ is large, so the old state is reset and the new colour is written in. The paper shows this is exactly a classic RNN gate in disguise (its Theorem 1), and calls it the selection mechanism.

The catch is that an input-dependent rule can no longer be computed as one big convolution, which is how S4 trained quickly. Much of the paper is a hardware-aware parallel scan that keeps the selective version fast on GPUs.

Try this

  • Look at the write-gate bars: the fixed model writes every token equally, while the selective model writes only the colours. Its state column stays one solid colour across the whole filler stretch.
  • Drag Fixed Δ from left to right and watch the fixed model's state: at small Δ it is a murky blend of everything, at large Δ it flickers with each filler. Its accuracy peaks somewhere in the middle and stays well below the selective model.
  • Set Filler after last colour to 0: the colour is now the very last token, so a large fixed Δ ("always overwrite") scores 100%. Add just 3 filler tokens and the best fixed Δ falls to about two thirds; with 10 or more it hovers around half. The selective model stays at 100% whatever the gap.
  • Tap a filler right after the last colour to turn it into a different colour: only the selective model's answer follows it immediately.

How this demo simplifies the paper

  • The weights are set by hand, not learned: w puts a large weight on an "is this a colour?" feature, so Δ ≈ 4 for colours and Δ ≈ 0.0025 for filler. A trained Mamba has to discover such a rule from data (the paper's Selective Copying and Induction Heads tasks test exactly this).
  • Only Δ is selective here. In Mamba, B and C are also computed from the input, which lets the model choose which state dimensions to write into and read from.
  • The model has 3 channels with a single state dimension each (N = 1, A = −1, B = C = 1), which is the setting of the paper's Theorem 1. Real Mamba blocks use thousands of channels, N = 16 state dimensions per channel, learned A, a short convolution, a gating branch and stacked layers.
  • The answer is read off as the strongest channel of the final state, instead of through a learned output layer.
  • The scan is a plain loop in JavaScript. The paper's main engineering contribution, a fused, hardware-aware parallel scan on GPUs, is not shown.
