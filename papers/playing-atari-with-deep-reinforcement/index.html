The idea in 60 seconds

From the paper's abstract: We present the first deep learning model to successfully learn control policies directly from high-dimensional sensory input using reinforcement learning. The model is a convolutional neural network, trained with a variant of Q-learning, whose input is raw pixels and whose output is a value function estimating future rewards.

We apply our method to seven Atari 2600 games from the Arcade Learning Environment, with no adjustment of the architecture or learning algorithm. We find that it outperforms all previous approaches on six of the games and surpasses a human expert on three of them.

The demo is reinforcement learning at its smallest. An agent walks a grid, gets −1 per step, −100 for stepping into lava and reaches the goal for free. From those rewards alone it has to discover a good route. The coloured cells show how much reward the agent expects from each cell, and the arrows show the move it would choose there.

Try this

  • Let Q-learning train and you'll see its greedy policy hug the edge of the lava: the shortest path. Switch to SARSA, which accounts for its own random exploration moves and learns a safer route further from the lava.
  • Click cells on the grid to add walls (and click again for lava) while it trains, and watch the values and arrows re-route.
  • Set exploration ε to 0. With no randomness the agent can lock onto its first route and never find a better one.
  • Lower the discount γ, and far-away rewards matter less, so values fade with distance from the goal.
